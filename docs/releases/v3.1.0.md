## What's new

Metronom 3.1.0 has a website, in all the app's languages, and links to it from the app.

### Website

- **[rask-project.github.io/metronom](https://rask-project.github.io/metronom/)** shows every feature, the downloads
  and a guide to tempo, time signatures and note values, in English, Brazilian Portuguese, Spanish, French and
  Italian.
- **Try it in the browser:** choose a time signature, a note value and a tempo, see the bar the app plays and press
  play to hear it with the app's clicks.

### App

- **Help:** the new **?** button next to Settings opens the guide in the app's language.
- **About** links to the website in the app's language.
