## What's new

Metronom 3.1.1 is now called just **Metronom** and polishes the time signature picker on macOS.

- **New name:** "Rask" is gone from the app's name — in the window title, the menu bar, About, the Linux
  applications menu, the Android launcher, the macOS disk image and the website.
- **Time signature on macOS:** the highlight behind the selected number is taller, so it frames the number instead
  of clipping it.
